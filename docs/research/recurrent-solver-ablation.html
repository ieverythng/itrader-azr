Compelling Proposition

  • Memory beyond the fixed rolling window.
  • Task-dependent filtering of market history.
  • Path-dependent value estimates.
  • Potentially larger gains on long horizons.

What Must Be Proven

  • Persistent state beats a reset-every-step window LSTM.
  • Per-step FiLM beats simple task concatenation.
  • State is used rather than ignored or saturated.
  • Held-out gains justify throughput and memory cost.

Critical Observation Contract

The current observation includes market features and task embedding, but not previous action, position, reward, unrealized PnL, or episode progress. Hidden state alone does not make a complete trade tracker.

price_dim = window_size * n_features
price_flat = obs[..., :price_dim]
task_embed = obs[..., price_dim:]
price_window = price_flat.reshape(..., window_size, n_features)
newest_bar = price_window[..., -1, :]

The environment orders the rolling window chronologically. The first feature row is the oldest bar; a recurrent model must take the last row as the newest input.

RLlib 2.9 Constraints

  • Use the native legacy recurrent ModelV2 contract: initial state, sequence lengths, and sequence-shaped forward processing.
  • Let RLlib reset state at episode boundaries; never infer reset from a zero-valued tensor.
  • batch_mode="complete_episodes" governs collection, not full-episode gradients.
  • BPTT is truncated by sequence chopping and max_seq_len.
  • Do not rely on an undocumented recurrent_policy=True flag.

  3. R2b: add per-step FiLM only after the recurrent baseline is green.
  4. R3: compare GRU only if recurrence wins.
  5. R4: add position and normalized episode progress to both matched heads.

Experiment Sequence

First lock sampling and reward on R0. Then compare R0→R1, R1→R2a, and R2a→R2b. Every cell holds data, tasks, seeds, reward, PPO budget, and observation contract constant.

Measure held-out return, Sharpe, drawdown, turnover, entropy, family/regime/horizon slices, steps per second, GPU memory, state norms, and confidence intervals.
