Conditioning placement (open proposal)

Use explicit placement names: R2a input concat, R2c-precell input/gate FiLM, R2c post-cell/readout FiLM, R2b initial-state FiLM, and R2d value-only placement. A post-cell/readout FiLM claim is readout-only only when no other task path (such as concat) reaches the cell; with concat, the transition is already task- conditioned and FiLM is an additional factor. Readout-first is a proposed order, not a settled memory-conditioning decision.

Attribution controls
