Can neural architectures be designed as compositions of abstraction-bearing objects?

This document formalizes an AB-level grammar for machine-learning modules: MLPs, convolutions, recurrence, attention, normalization, autoencoders, diffusion denoisers, and transformers as composable operators with predictable geometric effects.

1. Core thesis

An ML architecture can be treated as a typed composition of operators that transform distributions, geometry, memory, and controllability.

The AB system becomes useful if each object carries a semantic effect contract: what it tends to do to information, geometry, memory, invariance, compression, and generative dynamics.

Architecture = composition graph G = (V, E)
Each node v in V has:
  type: AB-level object
  map: f_v : X_in -> X_out
  effect signature: E(f_v)
  cost signature: C(f_v)
  information profile: I(f_v)
  geometry profile: Γ(f_v)

3. Operator view

Represent each module as an operator over a state distribution:

x₀ ~ P_data
h₁ = f₁(x₀)
h₂ = f₂(h₁)
...
y  = f_n(h_{n-1})

P_y = (f_n ∘ ... ∘ f₁)# P_data

The # symbol is pushforward: the architecture transforms an input distribution into an output distribution. Different AB1 objects differ by how they reshape the distribution.

4. AB1 object taxonomy

MLP / FFN

Token-wise nonlinear compressor / feature refiner

Applies learned nonlinear transformations independently per token or sample. It can expand hidden dimension, apply nonlinear gating, then compress back.

FFN(x) = W₂ σ(W₁x + b₁) + b₂

Effect: feature expansion, selection, compression, nonlinear basis transformation.

Attention

Content-addressable routing / attractor field

Creates dynamic edges between tokens based on similarity. It routes value vectors through a learned compatibility kernel.

Attn(Q,K,V) = softmax(QKᵀ / √d) V

Effect: long-range coupling, associative retrieval, dynamic graph construction.

Convolution

Local equivariant pattern extractor

Shares filters across space, preserving locality and translation structure.

y[i,j,c] = Σₐᵦₖ W[a,b,k,c] x[i+a,j+b,k]

Effect: locality, weight sharing, spatial hierarchy, inductive bias.

RNN / State-space

Sequential state accumulator

Compresses sequence history into a persistent state.

h_t = φ(W_x x_t + W_h h_{t-1})

Effect: temporal memory, causal recurrence, streaming compression.

Normalization

Manifold stabilizer / scale regulator

Controls activation statistics so composition remains trainable.

LayerNorm(x) = γ (x - μ) / √(σ² + ε) + β

Effect: stabilizes geometry, reduces scale drift, improves optimization.

Autoencoder

Explicit bottleneck / latent coordinate map

Encodes observations into a lower or more structured latent space, then reconstructs.

z = E(x),  x̂ = D(z)

Effect: dimensionality reduction, manifold discovery, lossy/lossless compression.

5. Transformer as AB2 → AB3 composition

A Transformer block can be written as a stable AB2 motif:

x' = x + Attention(LN(x))
y  = x' + FFN(LN(x'))

The AB2 block combines attention for routing, FFN for nonlinear feature refinement, residuals for identity preservation, and normalization for stability. Repeating this motif many times with a language-modeling objective creates an AB3 object: an LLM-like sequence distribution model.

P(x₁:T) = ∏ₜ P(x_t | x_<t)
logits_t = LMHead(Block_N ∘ ... ∘ Block_1(E(tokens)))

6. Attention as attractor field

Your intuition is strong: attention can be treated as a dynamic field over tokens. Query-key similarity creates a soft energy landscape; values are retrieved through that landscape.

A_ij = softmax_i(q_i · k_j / √d)
h_i' = Σ_j A_ij v_j

In the modern Hopfield interpretation, attention corresponds to an associative memory update: patterns can be retrieved through energy minima. This gives a mathematical bridge between attention and attractor dynamics.

Neural Workbench label: attention = associative routing object + soft attractor field.

8. Residual composition as controlled depth

Residual blocks can be read as near-identity updates:

x_{l+1} = x_l + F_l(x_l)

Stacking many residual blocks resembles a discretized dynamical system:

dx/dt = F_t(x)

AB interpretation: residual wiring is an architectural policy that allows deep composition without erasing the previous representation too quickly.

9. Diffusion models in the AB grammar

Each AB1 object can carry a vector of expected effects:

15. Key conclusion

Yes — the AB framework can be made operational. The next step is to annotate every module by its expected effect on information, geometry, memory, routing, and controllability.

An LLM is not merely “a Transformer.” It is an AB3 object produced by repeated AB2 Transformer blocks, trained under an autoregressive compression/prediction objective, with attention acting as dynamic associative routing and FFNs acting as token-wise nonlinear feature refinement.
