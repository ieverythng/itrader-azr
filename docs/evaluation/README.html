Four Separate Decisions

  • Evidence validity: are data, task/window, checkpoint/config/source/runtime, producer and control identities complete and bound, with correct causal/accounting semantics? Preserve invalid, incomplete or unbound attempts as raw/quarantined evidence with reasons, not certified comparisons.
  • Metric availability: does this metric have the required finite observations and dispersion? Valid positive, zero and negative net remain descriptive. Unavailable Sharpe is not measured zero; availability must have evidence and a reason when unavailable/unknown.
  • Uncertainty qualification: has a predeclared method passed support, independent synthetic calibration and confirmation for this estimand? Unresolved inference is not invalid arithmetic. A qualified interval crossing zero is inconclusive; support/method failure must not delete an otherwise valid descriptive estimate.
  • Promotion eligibility: eligible-for-review is not promoted. Held-out economics, matched controls, chronology, robustness, resource/runtime qualification and human review remain separate gates. Relative paired uplift does not establish positive absolute profitability.

build_evaluation_disposition is only a shape/vocabulary validator for caller-supplied statuses. It neither calculates cross-axis validity, derives inference, inspects metric values nor grants promotion. Callers must justify each axis; a well-shaped object alone is not a qualification certificate.

Current implementation limits matter: the terminal reporter requires finite Sharpe scalars, but marks Sharpe availability unknown because count/dispersion are absent. Legacy EpisodeEvidence returns scalar zero for fewer than two returns or near-zero sample SD; some legacy browser records retain that zero. Explicit availability exists in selected report/registry contracts, not every owner. Do not claim universal unavailable-Sharpe handling or infer availability from a legacy scalar.

Accounting And Trace Identity

The existing Discrete(3) actions select target positions -1/0/+1; repeated long means hold, not another buy. Starting flat, for arithmetic asset return r_t, target position p_t, H actual decisions and cost c in bps:

gross = sum(p_t * r_t)
turnover = sum(abs(p_t - p_(t-1))) + abs(p_H)
cost = turnover * c * 1e-4
net = gross - cost
direction = mean(p_t) * sum(r_t)
timing = gross - direction
net = direction + timing - cost

Direction uses the same-window matched long gross, not a hindsight best side; timing is an accounting residual, not independently identified forecasting alpha. Liquidation costs enter once on the last actual decision, not a fictitious bar. Continuation net, hypothetical round-trip net and actual terminal net are different quantities. Frozen-action repricing changes costs on the same trace; it is not retraining or proof the policy would react identically at another cost.

Bind source/panel/checkpoint/config/runtime/producer receipts, exact task hash, seed/symbol/session/row bounds, observation schema, causal past-window endpoint, actions/positions, return and cost trace, and terminal flag. Trace reconciliation checks contiguous reset-flat positions and exact ordering; the diagnostics' producer_provenance_verified: false remains explicit. Arithmetic identity does not authenticate a supplied checkpoint label.

One-bar net is well-defined; one-bar realized Sharpe is not. Flat/zero-SD series also cannot support measured Sharpe from a zero fallback. Optional past-only volatility scaling is not realized Sharpe and remains off/nonblocking here. Episode Sharpe units are per square-root bar; annualization needs an explicit periods contract. Overlapping episodes are not a stitched portfolio. Reported current drawdown is gross additive fractional-return episode drawdown, not compounded peak-relative or net drawdown. Gross returns +0.1/-0.1/-0.1 produce additive drawdown 0.2, not compounded peak-relative drawdown 0.19.

Q24 Weights And Q25 Denominator

The implemented reporter is strictly 128 tasks / 32 anchors / 12 symbols, horizons 96/128/160/200, exact 1 bp and full horizon: steps == horizon == end_idx - start_idx. It is not a generic small-panel/variable-horizon robustness reporter.

Q24 averages four horizons within anchor, anchors within symbol, then 12 symbols equally, with identical weights for policies and paired controls. With n_s anchors for symbol s, each episode weight is 1/(12 * n_s * 4). Retain labeled raw means and per-horizon diagnostics; missing coverage rejects. Show flat/long/short/random/architecture-and-state-matched seeded untrained controls. Choose the stronger constant direction once across the whole panel, not per-anchor hindsight. Control labels require caller-owned provenance.

Q25 is secondary net_bps_per_bar = 10000 * episode_net_return / actual_steps. Normalize each episode first, then apply Q24 weights. Require positive integral steps and consistent endpoints; never substitute lookback, exposure/training steps, a clamp or a pooled-return/pooled-step ratio. Liquidation adds cost, not a bar. A shortened episode is censored and rejected from this fixed-panel primary, not normalized into a complete result. Neither weighting nor this diagnostic changes rewards, PBT scores or the primary terminal-net estimand.
