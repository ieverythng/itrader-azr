# Daily Log Commands

Use these prompts directly in chat.

## During Session
`Append an automatic daily log entry to docs/daily_logs/YYYY-MM-DD.md with what changed, why, validation, and follow-ups.`

## End Of Session
`Generate daily log for today and append a final AUTOMATIC DAILY LOG section to docs/daily_logs/YYYY-MM-DD.md.`

## Notion Export Block
`Generate a Notion-ready daily summary from docs/daily_logs/YYYY-MM-DD.md with sections: Outcomes, Changes, Validation, Pending.`
