# Daily Logs

Use this folder to keep a persistent engineering record across sessions and models.

## File Naming
- One file per day: `YYYY-MM-DD.md`
- Example: `2026-02-15.md`

## Workflow
1. Start from `_TEMPLATE.md`.
2. Append entries during the day after meaningful work.
3. Close with an `End Of Session` section.

## Suggested Prompt
Use this prompt in chat whenever you want automatic logging:

`Generate daily log for today from this session and append it to docs/daily_logs/YYYY-MM-DD.md`
